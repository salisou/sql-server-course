# ERPAnalyticsDb — database ERP didattico

Modello originale ispirato alle aree funzionali pubblicamente descritte da SAM ERP2 e Arca Evolution, senza replicare codice, schema proprietario o dati proprietari.

Aree: anagrafiche, CRM, vendite, acquisti, magazzino/logistica, produzione/MRP, qualità, contabilità, finanza, controllo di gestione e audit.

I dati del seed saranno sintetici ma realistici e riproducibili. Ogni tabella avrà 100 record generati da T-SQL, utili per SQL Server, Data Analysis, BI, API, Dapper ed EF Core.

Fonti di riferimento: Centro Software descrive aree CRM, commerciale, acquisti/scorte/logistica, produzione, qualità, amministrazione/finanza e controllo di gestione; Arca Evolution descrive amministrazione, ordini, logistica, produzione, CRM, controllo e finanza.
